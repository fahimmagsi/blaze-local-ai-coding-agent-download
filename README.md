## 🌟 Key Capabilities

- **🤖 100% Offline Local LLM Inference**: Load any `.gguf` quantized model (Qwen 2.5 Coder, Llama 3, Mistral, Phi-3) directly on your machine with zero latency and zero data leakage.
- **🔥 Autonomous AI Agent Loop**: Toggle **Auto Mode** to let Blaze Agent formulate plans, write code across project files, run workspace tools, and verify unit tests autonomously.
- **⚡ Model Context Protocol (MCP)**: JSON-RPC 2.0 stdio tool execution with user approval controls and sandboxed file tools.
- **🔍 Interactive Unified Diff Reviewer**: Inspect and approve AI-generated code edits line-by-line before applying.
- **📝 Tabbed Code Editor**: Syntax highlighting, line number gutter, multi-step undo/redo (`Ctrl+Z`/`Ctrl+Y`), regex find & replace (`Ctrl+F`/`Ctrl+H`), and auto-save.
- **🎨 Sleek Dark Theme**: Modern dark glassmorphism layout with customizable layout and quick-access shortcuts.
